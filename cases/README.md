#   Lista de casos
Cada carpeta representa un caso de Análisis, sea un análisis completo o herramientas contruidas para poder realizar el análisis. A continuación se enlistan los casos y qué es lo que encontrarás en esa carpeta. Dentro de cada una, hay una descripción a mucho mayor detalle sobre el probelma.

1. Invfluenza vs COVID: Se buscó revisar cómo cambiaron los positivos de influenza detectados antes, durante y después del COVID-19.

2. VPH: En un estudio de VPH se buscó una forma de obtener los grupos de genotipos más comúnes en una población de mujeres, así como maneras en qué presentar los resultados.
